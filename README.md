I'm a **forward-deployed AI engineer** specializing in **computer vision**, **on-device machine learning**, and **real-time inference optimization**. I port and accelerate deep learning models — **object detection, segmentation, and tracking** — onto **Android** (`TensorFlow Lite / LiteRT`, `ONNX Runtime Mobile`, `NDK`), **embedded Linux edge devices**, and **CPU-only machines** using **INT8 / FP16 quantization**, `OpenVINO`, `ncnn`, and `C++ / OpenCV`. I also optimize **audio and compact LLM models** for mobile and CPU targets (`ExecuTorch`, `CoreML`, `ONNX`).

On the IoT side, I build **ESP32 firmware** (`ESP-IDF`, `MQTT`, `RTSP`) that captures and streams data to the edge nodes running the models. **Microcontrollers are my sensing, telemetry, and control layer — not my inference layer**, apart from the occasional tiny TinyML experiment.

MCUs handle I/O and telemetry — inference stays on phone / SBC / CPU-class hardware. |
