## ⚡ What I Build

| 🧠 **Computer Vision** | 📱 **Android On-Device AI** |
|---|---|
| Designing and optimizing lightweight CV architectures — detection, segmentation, tracking — for real hardware constraints, not cloud benchmarks. | Native Android pipelines: `CameraX` → `TFLite / LiteRT`, `ONNX Runtime Mobile`, GPU/NPU delegate acceleration via `Kotlin / JNI`. |

| ⚙️ **CPU & Edge Inference** | 📡 **AI + IoT Systems** |
|---|---|
| INT8/FP16 quantization and runtime selection with `ONNX Runtime`, `OpenVINO`, `TensorRT`, `ncnn`, and `C++ / OpenCV` to hit real-time on hardware without a GPU. | End-to-end vision + telemetry pipelines on ESP32-class hardware: `ESP-IDF`, `MQTT`, `GStreamer`, `RTSP`, custom firmware. |
